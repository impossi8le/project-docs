# ИИ-документация компании

Добро пожаловать во внутреннюю документацию нашей компании.

Здесь собрана документация по всем проектам: техническая (README, API, схемы), вики и управленческая (статусы, планы, встречи). Документация ведётся по подходу **Docs-as-Code** и живёт в репозитории вместе с кодом.

## Быстрый старт

- 📦 **Проекты** — обзор всех проектов, статусы и ссылки на детальную документацию.
- 🔧 **Техническая документация** — автогенерируемые страницы API из docstrings (mkdocstrings).
- 📚 **Вики / база знаний** — регламенты, гайды и общие материалы.

## Как добавить новый проект

Документация каждого проекта — это просто папка и страница в разделе **Проекты**. Подробный регламент — на странице [Регламент работы с документацией](wiki/working-agreement.md).

## Для разработчиков

Запуск локально:

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Локальный сервер (http://localhost:8000)
mkdocs serve

# 3. Сборка статического сайта в каталог site/
mkdocs build
```

## Автоматизация

Документацией можно управлять через MCP-сервер или напрямую через GitHub MCP — создавать страницы проектов, добавлять разделы, собирать сайт из диалога с ИИ-ассистентом.
