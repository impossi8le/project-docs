# VPN Landing Site

> Статус: **эксплуатация** · Обновлено: 2026-08-01

## Обзор

Landing page (сайт-визитка) для VPN-сервиса. Одностраничный сайт с информацией о тарифах, преимуществах и реферальной программе.

**Репозиторий:** `https://github.com/impossi8le/BusinessCardWebsiteForVPN`  
**Домен:** `https://vpnbotfree.ru`  
**Путь:** `/var/www/vpnbotfree_r_usr/data/www/vpn-landing-site/`

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Фреймворк | Vue 3 |
| Сборщик | Vite 4 |
| Стили | CSS (scoped в компонентах) |
| Хостинг | FastPanel, статические файлы |

## Структура

```
├── index.html                  # Главная страница
├── vite.config.js              # Конфигурация Vite
├── package.json                # Зависимости (vue 3, vite 4)
├── src/
│   ├── main.js                 # Точка входа Vue
│   ├── App.vue                 # Корневой компонент
│   ├── style.css               # Глобальные стили
│   └── components/
│       ├── HeroSection.vue     # Герой: заголовок, CTA, статистика
│       ├── PricingSection.vue  # Тарифы + калькулятор стоимости
│       ├── BenefitsSection.vue # Преимущества и платформы
│       ├── HowItWorksSection.vue # Как это работает (4 шага)
│       ├── ReferralSection.vue # Реферальная программа
│       ├── FAQSection.vue      # Часто задаваемые вопросы
│       ├── ContactSection.vue  # Контакты и поддержка
│       └── FooterSection.vue   # Подвал
└── dist/                       # Сборка
```

## Компоненты

| Компонент | Описание |
|-----------|----------|
| `HeroSection` | Анимированный фон, заголовок, кнопка «Запустить в Telegram», статистика (1000+ пользователей, 99.9% uptime, 6+ серверов) |
| `PricingSection` | 4 тарифа (30/90/180/360 дней), интерактивный калькулятор со скидками, баннер 30-дневного триала |
| `BenefitsSection` | 6 преимуществ (скорость, безопасность, серверы, устройства, поддержка, трафик) + список платформ |
| `HowItWorksSection` | 4 шага: запуск бота → выбор тарифа → оплата → подключение |
| `ReferralSection` | 5% скидка за каждого друга, 3 шага получения |
| `FAQSection` | Ответы на частые вопросы |
| `ContactSection` | Ссылки на Telegram-бота и группу поддержки |

## Дизайн

- Тёмная тема с градиентами (primary: `#4C6FFF`, accent: `#00D1FF`)
- Адаптивная вёрстка (мобильная + десктоп)
- Анимации: вращающийся градиентный фон, hover-эффекты карточек

## Запуск

```bash
npm install
npm run dev      # Разработка
npm run build    # Сборка в dist/
```
