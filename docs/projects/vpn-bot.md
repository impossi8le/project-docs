# VPN Telegram Bot

> Статус: **эксплуатация** · Обновлено: 2026-08-01

## Обзор

VPN Telegram Bot — это Telegram-бот для управления VPN-подписками и автоматической генерации VPN-конфигурационных файлов для пользователей. Бот предоставляет удобный интерфейс для выбора подписки, оплаты и получения конфигурационных файлов для подключения к VPN.

**Репозиторий:** `https://github.com/impossi8le/freebotvpn`  
**Сервер:** `vpnbotfree.ru` → `/var/www/vpnbotfree_r_usr/data/www/vpnbotfree.ru/`  
**Деплой:** Docker Compose (MySQL + бот + Adminer) на FastPanel

### База данных

MySQL, основная таблица — `users` (данные пользователей, подписки, устройства). Поддерживаются реферальные коды, привязка почты, история платежей, система тикетов поддержки.

### Интеграции

- **ЮKassa** — приём платежей по картам
- **n8n** — вебхук для генерации OpenVPN-конфигураций (`http://194.87.252.181:5678/webhook/generate-config`)
- **SSH (paramiko)** — управление конфигурациями на VPN-серверах
- **SMTP** — отправка кодов верификации почты

## Администрирование

### Админ-панель в Telegram

Доступна администраторам (ID: 377182640, 459236851) через команды:

- `/admin` — вход в админ-панель
- Статистика, управление пользователями, SQL-запросы
- SSH-команды к серверам
- Управление серверами и тарифами

### Бот поддержки

`helpBot.py` — отдельный бот для тикет-системы поддержки с:
- Созданием и отслеживанием тикетов
- Классификацией обращений (AI-триаж)
- Прикреплением файлов
- Пересылкой сообщений между пользователем и администратором
- Сводкой `client360` — полная картина по клиенту

## Технические детали

### Запуск

```bash
# Docker Compose
docker-compose up -d

# Без Docker (через FastPanel)
source venv/bin/activate
python bot1.py &   # Основной бот
python helpBot.py & # Бот поддержки
```

### Переменные окружения (.env)

Ключевые переменные: `TELEGRAM_TOKEN`, `TELEGRAM_HELP_BOT_TOKEN`, `DB_*`, `YOOKASSA_*`, `SMTP_*`, `GENERATE_CONFIG_API_URL`. Полный список — в `includes/const_inc.py`.

### Тестовый режим

`PAYMENT_TEST_BYPASS_ENABLED=1` с кодом `PAYMENT_TEST_BYPASS_CODE` (по умолчанию `ch8917`) — для тестирования без реальной оплаты (только для админов).
