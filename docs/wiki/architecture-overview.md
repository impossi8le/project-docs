## Связи между проектами

### VPN Telegram Bot ↔ Commuspace.ru

| Общее | Описание |
|-------|----------|
| **Цены** | Одинаковые тарифы (140/400/750/1300 ₽) и скидки (5% реферальная, 10-15% комплект) |
| **ЮKassa** | Один и тот же shop_id (472651) для приёма платежей |
| **VPN-серверы** | Оба проекта генерируют конфиги на тех же серверах через SSH |
| **SMTP** | Одна почта: `info@commuspace.ru` через `mail.commuspace.ru` |
| **База данных** | Разные БД, но одинаковая структура users/servers |

### VPN Telegram Bot ↔ n8n

| Связь | Описание |
|-------|----------|
| **Генерация конфигов** | Бот отправляет POST на `http://194.87.252.181:5678/webhook/generate-config` (n8n webhook) |
| **Параметры** | `days`, `region`, `chat_id` → n8n генерирует `.ovpn` файл |

### n8n ↔ LLM Router

| Связь | Описание |
|-------|----------|
| **Оркестрация** | n8n использует LLM Router для multi-agent workflow |
| **Модели** | Ollama с llama3.1, qwen2.5, codestral на GPU |
| **Память** | PostgreSQL + Qdrant для долгосрочной памяти |

### Help Bot ↔ Client360

| Связь | Описание |
|-------|----------|
| **Поддержка** | helpBot.py собирает полную картину по клиенту из MySQL |
| **AI-триаж** | Классифицирует обращения (может использовать LLM Router) |

## Поток данных: покупка VPN

```
1. Пользователь открывает бота @free1vpnbot
   или сайт commuspace.ru

2. Выбирает тариф (30/90/180/360 дней) и устройства

3. Бот: создаёт pending_payment в MySQL, отправляет ссылку ЮKassa
   Сайт: бэкенд создаёт платёж в ЮKassa, возвращает confirmationUrl

4. Пользователь оплачивает на стороне ЮKassa

5. ЮKassa уведомляет:
   Бот: проверка через API / получение webhook
   Сайт: webhook POST /api/webhooks/yookassa

6. Генерация конфига:
   Бот: n8n webhook → OpenVPN
   Сайт: SSH-скрипты на сервере через BullMQ очередь

7. Доставка конфига пользователю:
   Бот: в Telegram
   Сайт: на email или в Telegram
```
