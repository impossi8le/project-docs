# Вики / база знаний

Общие материалы команды: регламенты, гайды, справочники.

- [Регламент работы с документацией](working-agreement.md) — как вести документацию в этом репозитории.
- [Теги](../tags.md) — все теги материалов.

## Правила коротко

1. Документация живёт в репозитории и меняется через pull request.
2. Каждый проект — отдельная папка в `docs/projects/`.
3. Техническая документация автогенерируется из docstrings.
4. Чувствительные материалы защищаются общим паролем.
