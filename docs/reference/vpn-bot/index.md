## API генерации конфигураций

Генерация OpenVPN-конфигураций происходит через n8n webhook:

**POST** `/webhook/generate-config`

**Тело запроса:**
```json
{
  "days": 30,
  "region": "netherlands",
  "chat_id": "123456789"
}
```

**Ответ (успех):**
```json
{
  "status": "ok",
  "filename": "client_123456789_netherlands.ovpn"
}
```

**Коды ошибок:**
- `USER_NOT_FOUND` — пользователь не найден
- `SERVER_NOT_FOUND` — сервер недоступен
- `TIMEOUT` — превышено время ожидания (120 сек)
- `NETWORK_ERROR` — ошибка сети
- `INVALID_RESPONSE` — некорректный ответ сервера

|---------|----------|

| `/context` | Снимок контекста последнего тикета |

| `/help` | Справка по командам |

## Меню Telegram-бота

Главное меню:
- 🛒 **Купить VPN** — выбор тарифа и оплата
- 🤖 **Купить proxy TG** — выбор прокси для Telegram
- 📧 **Привязать почту** — верификация email
- 👤 **Мой профиль** — статус подписки, конфиги
- 🎁 **Реферальная программа** — код и скидки
- ❓ **Помощь** — инструкции и поддержка
